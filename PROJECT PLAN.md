## Project Planning

The project is divided into smaller deliverables to ensure that the WASLAH platform can be completed within the available development timeframe.

### Development Plan

| Day | Main Deliverable | Tasks |
|---|---|---|
| Day 1 | Planning & Design | Requirements review, project scope, user stories, ERD and project setup |
| Day 2 | Database & Backend Foundation | PostgreSQL setup, entities, relationships, repositories and service layer |
| Day 3 | Core APIs | User, profile and job APIs |
| Day 4 | Authentication & Authorization | Registration, login, JWT and role-based authorization |
| Day 5 | Account Security | Password recovery, password reset and rate limiting |
| Day 6 | Booking Module | Booking APIs, validation and booking business rules |
| Day 7 | Testing & Validation | API testing, authentication testing, authorization and validation testing |
